# Data Files

These are the test/sample data files.

- `old_schedulizer-CS2023-readtest.csv` is a sample CSV file used for auto-testing the old CSV reading functionality.
- `reports-schedulizer_course_sections-CSDS2025.xlsx` is the XLSX output from the "schedulizer course sections" report created in 2025.
- `schedulizer-CSDS2025.xlsx` is the XLSX output of the 2025 Schedulizer.
- `test_multiple/*` contains XLSX files used to test the multiple-schedule features being developed in `feature/multiple`. It's not clear how YueSi used them.

The old files are archived; if needed, see the history of `https://github.com/senior-knights/course-schedulizer/tree/production/client-course-schedulizer/csv`.
